# دليل التصميم — GHIS HR / Style guide

الاستايل ده ثابت للنظام كله. أي شاشة جديدة لازم تستخدم الـ tokens والـ classes دي، ومن غير ألوان أو خطوط مكتوبة جوه الصفحة.
في النظام صفحة حية بتعرض كل ده للسوبر أدمن: **إدارة النظام ← دليل التصميم** (`?r=styleguide`).

## 1. الهوية
| | |
|---|---|
| **اللوجو** | `public/hr/assets/img/logo-{480,800,1600}.png` (و `.webp`). دي نسخة منضّفة من اللوجو الأصلي: اتشال الإطار الأخضر الرفيع واتصلحت ضوضاء JPEG بحيث الألوان بقت مطابقة بالظبط. بيتعرض دايمًا على أرضية بيضا. في صفحة الدخول بيتعرض على "لوحة" بيضا فوق الخلفية الزرقا. |
| **الأيقونة** | `icon-32.png` (favicon) و `icon-180.png` (iPhone) و `icon-512.png` |
| **الخط** | **IBM Plex Sans Arabic** للعربي والإنجليزي، أوزان 400/500/600/700. محفوظ على السيرفر في `assets/fonts` لأن الـ CSP مش بيسمح بخطوط من بره. الرخصة SIL OFL 1.1 (`fonts/OFL.txt`). |

## 2. الألوان (CSS tokens في `app.css`)
| Token | القيمة | الاستخدام |
|---|---|---|
| `--blue` | `#1E4CA1` | لون أساسي (من اللوجو): الأزرار الأساسية، والروابط، والعناصر النشطة |
| `--blue-700` | `#163A7D` | hover، والعناوين المهمة |
| `--blue-50` | `#EEF3FB` | خلفية العنصر النشط في القائمة، والشارات الزرقا |
| `--green` | `#017538` | لون ثانوي (من اللوجو): النجاح، والانصراف، والحضور |
| `--ochre` / `--ochre-700` | `#B97A22` / `#8A5A14` | لون دافي للتمييز: شريط الكروت المهمة والمؤشرات. نصوص الشارات بـ `--ochre-700` |
| `--bg` | `#F7F3EC` | خلفية الصفحة (عاجي دافي) |
| `--surface` | `#FFFFFF` | الكروت والجداول |
| `--line` | `#E6DED1` | الحدود |
| `--text` / `--text-2` / `--muted` | `#2A2621` / `#54504A` / `#6F665B` | النصوص (رمادي دافي) |
| `--danger` / `--warning` | `#B3402B` / `#9A5B0E` | الأخطاء والتحذيرات |

- كل لون ليه نسخة **Dark mode** بتشتغل لوحدها حسب إعداد الجهاز.
- التباين اتقاس ويعدّي معيار WCAG AA (4.5:1) لكل النصوص على خلفياتها. مثلًا: النص الثانوي 5.1، والأزرق على الخلفية 7.3، والأبيض على الأزرق 8.1.

## 3. المكونات
| Class | الاستخدام |
|---|---|
| `.page-head` + `h1` + `.sub` | رأس كل صفحة: العنوان وسطر وصف، وعلى الطرف التاني الأزرار أو الفلاتر |
| `.card` / `.card.accent` / `.card.narrow` | كارت. `accent` بيضيف شريط ذهبي فوق للكروت المهمة |
| `.stats` + `.stat` (`.green` `.ochre` `.warn`) | مربعات الأرقام في لوحة التحكم |
| `.btn` + `.primary` `.success` `.danger` `.ghost` `.small` `.big` `.wide` | الأزرار. **زرار primary واحد بس في كل نموذج** |
| `.badge` + `.green` `.blue` `.ochre` `.red` | الحالات (معتمد، تحت المراجعة، مرفوض…) |
| `.flash` + `.ok` `.err` `.warn` `.info` | رسائل النظام |
| `.table-wrap > table` | الجداول. الأرقام بـ `.num` عشان تتصف تحت بعض |
| `.form-grid` + `label > input` | النماذج. الحقل الطويل بياخد `.span2`، والخطأ `.has-err` + `.err-text` |
| `.filters` | شريط الفلاتر فوق الجداول |

## 4. اللغتين والاتجاه (RTL / LTR)
- `<html lang dir>` بيتغير حسب اللغة: العربي `rtl` والإنجليزي `ltr`.
- **في الـ CSS، استخدم الخصائص المنطقية بس:** `margin-inline-start`، و`padding-inline-end`، و`inset-inline-start`، و`border-inline-start`، و`text-align: start`. ماتستخدمش `left`/`right`.
- الحقول اللي محتواها إنجليزي دايمًا (اسم المستخدم، كلمة المرور، التليفون، الإحداثيات) بتاخد `dir="ltr"`.
- **النصوص:** كل نص ظاهر يتكتب بالعربي جوه `__('…')`، وترجمته الإنجليزي في `app/lang/en.php`. القيم المتغيرة بتتحط بـ `%s`/`%d`: `__('تم تسجيل الحضور الساعة %s.', $t)`.
- بعد أي نص جديد شغّل `php bin/i18n_tool.php check`. لازم يطلع `0 missing`.
- نصوص المتصفح (JavaScript) بتتعرّف في `js_strings()` في `app/lib/i18n.php`.
- **مايتترجمش:** أسماء الموظفين، والبيانات اللي المستخدم بيكتبها، وقالب Excel (عربي بس).

## 5. قواعد عامة
1. مفيش `style="…"` ولا `<script>` جوه الصفحات، لأن الـ CSP بيمنعهم. كل حاجة في `app.css` و `app.js`.
2. المسافات من مضاعفات 4px. الزوايا `--r-sm` (8px) للحقول و `--r` (12px) للكروت.
3. الأيقونات قليلة، والنص أوضح من الأيقونة.
4. الشاشات لازم تشتغل على موبايل عرضه 360px. القائمة الجانبية بتتحول لقائمة منزلقة تحت 860px.
